Common Table Expressions

Como nomear um bloco de consulta SQL para reaproveitar dentro de uma query maior — sem empilhar subconsultas ilegíveis.

WITH vendas_2026 AS (
  SELECT loja, consultor, valor
  FROM vendas
  WHERE ano = 2026
)
SELECT loja, SUM(valor) AS total
FROM vendas_2026
GROUP BY loja;

O que é

Uma CTE dá um nome temporário a um resultado de consulta, válido só dentro da instrução que a define. É como declarar uma variável — só que a "variável" é uma tabela.

  • Existe apenas durante a execução daquela consulta — não fica salva no banco, como uma tabela ou view ficariam.
  • Pode ser referenciada mais de uma vez na consulta principal.
  • Deixa consultas com várias etapas legíveis de cima para baixo, em vez de subconsultas aninhadas umas dentro das outras.

CTE recursiva

Uma CTE pode referenciar a si mesma — útil para percorrer dados hierárquicos, como uma árvore de cargos (funcionário → gestor → gestor do gestor...).

WITH RECURSIVE hierarquia AS (
  SELECT id, nome, gestor_id FROM funcionarios WHERE gestor_id IS NULL
  UNION ALL
  SELECT f.id, f.nome, f.gestor_id
  FROM funcionarios f
  JOIN hierarquia h ON f.gestor_id = h.id
)
SELECT * FROM hierarquia;
